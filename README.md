# 🛒 Carrinho de Compras

Projeto simples de carrinho de compras, desenvolvido para praticar JavaScript, manipulação do DOM e lógica de atualização de valores e itens dinamicamente.

Permite que o usuário adicione e remova produtos, além de calcular automaticamente o total do pedido.

## 🚀 Demonstração

🔗 [Acesse o projeto online](https://carrinho-de-compras-eta-eight.vercel.app/)

## 📌 Funcionalidades

- Listagem de produtos com nome e preço.
- Adição e remoção de itens no carrinho.
- Cálculo automático do valor total.
- Interface clara e responsiva para melhor usabilidade.
